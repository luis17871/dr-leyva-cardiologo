# Dr. Leyva - Cardiólogo

Sitio web estático, profesional y responsive (HTML, CSS y JS puros).

## Personalizar
- La foto está en `assets/doctor.jpg` (ideal: reemplazarla por una versión de mayor resolución, mínimo 800×1200).
- Edita nombre, teléfono, dirección y horarios en `index.html`.
- Formación: hay un bloque comentado (`FORMACIÓN`) en la sección "Sobre mí" listo para completar con datos reales.
- Cambia el número de WhatsApp en `script.js` (`WHATSAPP`) y en los enlaces `wa.me` de `index.html`.
- Cambia la ubicación del mapa en el `iframe` (parámetro `q=`).

## Publicar
Settings > Pages > Source: rama `main`, carpeta `/ (root)`.
